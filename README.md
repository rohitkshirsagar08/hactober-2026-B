# Pesticide Label Reader for Indian Farmers

## About the Project

The Pesticide Label Reader is an open-source project designed to help Indian farmers read information printed on pesticide labels.

It uses Optical Character Recognition (OCR) to extract text from uploaded label images.

The application supports English, Hindi, and Marathi to make label information more accessible.

## Features

- Upload a pesticide label image.
- Extract text using OCR.
- Support English, Hindi, and Marathi.
- Display extracted text on a simple web interface.

## Important Safety Note

OCR may incorrectly recognize pesticide names, dosage numbers, and safety instructions. Always verify the extracted text against the original product label and trusted agricultural guidance. Do not rely on this application alone to make pesticide-use decisions.
